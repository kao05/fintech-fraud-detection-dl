## Conjunto de datos y exploración básica

Indica la fuente o enlace del conjunto, el número de ejemplos y las variables o características de entrada. Presenta una revisión de datos faltantes y duplicados, al menos dos gráficas pertinentes y una breve interpretación de los hallazgos.

### Adaptación

- Clasificación: muestra la cantidad de ejemplos por clase e identifica si existe desbalance. Analiza las características, en caso de que existan.
- Regresión: muestra la distribución de la variable objetivo y explora su relación con las variables predictoras.
- Imágenes o detección: muestra ejemplos con sus etiquetas o anotaciones, la distribución de clases y características como dimensiones y cantidad de imágenes u objetos.

Se debe de analizar a profundidad el dataset para ver con lo que se esta tratando.

El proyecto deberá abordar un problema con una complejidad acorde con la materia de Deep Learning, utilizando un conjunto de datos distinto de los empleados en las prácticas realizadas en el curso.

Para proyectos de clasificación de imágenes, se requiere un mínimo de 2,000 imágenes originales y al menos 200 por clase. Para datos tabulares, se requieren 5,000 registros como mínimo, además de justificar la pertinencia de utilizar una red neuronal. Estas cantidades corresponden al conjunto completo antes de dividirlo en entrenamiento, validación y prueba; el aumento de datos no cuenta para alcanzar el mínimo.

En detección de objetos, texto o series temporales, la suficiencia del conjunto se valorará según la tarea y el modelo propuesto. Cualquier excepción deberá justificarse durante el primer avance.
